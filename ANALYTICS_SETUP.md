# Настройка аналитики для сайта

Этот документ описывает процесс настройки Google Analytics 4 и Яндекс Метрики для отслеживания посещаемости сайта.

## Google Analytics 4

### 1. Создание аккаунта Google Analytics

1. Перейдите на сайт [Google Analytics](https://analytics.google.com/)
2. Войдите с помощью аккаунта Google
3. Нажмите "Начать измерение"
4. Создайте новый аккаунт:
   - Название аккаунта: "ТОО Центр цифровой безопасности" (или любое другое)
   - Выберите настройки общего доступа к данным (по желанию)

### 2. Создание ресурса (Property)

1. Название ресурса: "digisec.kz"
2. Часовой пояс: (UTC+05:00) Астана
3. Валюта: Казахстанский тенге (KZT)
4. Категория отрасли: Технологии
5. Размер компании: Малый

### 3. Настройка потока данных

1. Выберите платформу: **Веб**
2. URL веб-сайта: `https://digisec.kz`
3. Название потока: "digisec.kz - main"
4. Нажмите "Создать поток"

### 4. Получение Measurement ID

После создания потока данных вы увидите **Measurement ID** вида `G-XXXXXXXXXX`.

### 5. Настройка в коде

Откройте файл `src/components/Analytics.tsx` и замените:

```typescript
const GA_MEASUREMENT_ID = "G-XXXXXXXXXX"; // Replace with your GA4 ID
```

на ваш реальный Measurement ID:

```typescript
const GA_MEASUREMENT_ID = "G-ABC1234567"; // Пример
```

## Яндекс Метрика

### 1. Создание счётчика

1. Перейдите на сайт [Яндекс Метрика](https://metrika.yandex.ru/)
2. Войдите с помощью Яндекс ID
3. Нажмите "Добавить счётчик"

### 2. Настройка счётчика

1. Название счётчика: "ТОО Центр цифровой безопасности"
2. Адрес сайта: `https://digisec.kz`
3. Часовой пояс: (UTC+05:00) Астана, Алматы
4. Включите следующие опции:
   - ☑ Вебвизор
   - ☑ Карта кликов
   - ☑ Карта скроллинга
   - ☑ Аналитика форм
   - ☑ Точный показатель отказов

5. Нажмите "Создать счётчик"

### 3. Получение ID счётчика

После создания вы получите номер счётчика (например: `12345678`)

### 4. Настройка в коде

Откройте файл `src/components/Analytics.tsx` и замените:

```typescript
const YM_COUNTER_ID = "XXXXXXXX"; // Replace with your Yandex Metrika ID
```

на ваш реальный ID счётчика:

```typescript
const YM_COUNTER_ID = "12345678"; // Пример
```

## Проверка работы аналитики

### Google Analytics

1. После внесения изменений и деплоя сайта
2. Перейдите в Google Analytics → Отчёты → Реал-тайм
3. Откройте свой сайт в браузере
4. В течение нескольких секунд вы должны увидеть активного пользователя

### Яндекс Метрика

1. После внесения изменений и деплоя сайта
2. Перейдите в Яндекс Метрика → Отчёты → Посетители онлайн
3. Откройте свой сайт в браузере
4. Вы должны увидеть активного посетителя на карте

## Дополнительные настройки

### Google Analytics

#### Настройка целей (Conversions)

1. Перейдите в Настройка → События
2. Создайте события для отслеживания:
   - Клики по кнопкам "Связаться с нами"
   - Заполнение формы обратной связи
   - Переходы на страницу контактов

#### Настройка отчётов

1. Отчёты → Библиотека
2. Создайте пользовательские отчёты для:
   - Источники трафика
   - Популярные страницы
   - Географическое распределение посетителей

### Яндекс Метрика

#### Настройка целей

1. Настройка → Цели
2. Создайте цели:
   - **Посещение страниц**: URL содержит `/contacts`
   - **JavaScript-событие**: Клик по кнопке "Связаться"
   - **Отправка формы**: Успешная отправка контактной формы

#### Настройка сегментов

1. Отчёты → Сегменты
2. Создайте сегменты:
   - Посетители из Казахстана
   - Мобильные пользователи
   - Повторные посетители

## Соответствие законодательству

### Согласие на использование cookies

Рекомендуется добавить уведомление о cookies на сайт в соответствии с законодательством РК и требованиями GDPR (если есть посетители из ЕС).

Пример текста:

> "Мы используем файлы cookie для улучшения работы сайта и анализа посещаемости. Продолжая использовать сайт, вы соглашаетесь с использованием cookie-файлов."

### Политика конфиденциальности

Обновите политику конфиденциальности, указав:
- Какие данные собираются (IP-адреса, действия пользователей)
- Для чего используются (улучшение сайта, аналитика)
- С кем данные могут быть переданы (Google, Яндекс)
