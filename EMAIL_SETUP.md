# Настройка почты для формы обратной связи

Форма обратной связи на сайте использует почтовый адрес **info@digisec.kz** для получения сообщений от посетителей.

## Как это работает

Форма обратной связи работает по принципу `mailto:` - при отправке формы открывается почтовый клиент пользователя с предзаполненными полями:
- **Кому:** info@digisec.kz
- **Тема:** Обращение от [Имя пользователя]
- **Сообщение:** Данные из формы (имя, email, телефон, компания, сообщение)

## Настройка почтового ящика info@digisec.kz

### Вариант 1: Использование корпоративной почты (рекомендуется)

1. **Создайте почтовый ящик у вашего хостинг-провайдера или используйте Google Workspace/Microsoft 365:**
   - Google Workspace: https://workspace.google.com/
   - Microsoft 365: https://www.microsoft.com/ru-ru/microsoft-365
   - Яндекс.Почта для домена: https://yandex.kz/support/domain/

2. **Создайте почтовый ящик info@digisec.kz в панели управления вашего провайдера**

3. **Настройте DNS записи для домена digisec.kz:**
   ```
   MX записи (пример для Google):
   MX 1 ASPMX.L.GOOGLE.COM
   MX 5 ALT1.ASPMX.L.GOOGLE.COM
   MX 5 ALT2.ASPMX.L.GOOGLE.COM
   MX 10 ALT3.ASPMX.L.GOOGLE.COM
   MX 10 ALT4.ASPMX.L.GOOGLE.COM

   SPF запись:
   TXT v=spf1 include:_spf.google.com ~all

   DKIM запись: (предоставляется провайдером)
   DMARC запись:
   TXT v=DMARC1; p=quarantine; rua=mailto:dmarc-reports@digisec.kz
   ```

4. **Настройте переадресацию (опционально):**
   - Можно настроить переадресацию с info@digisec.kz на личный email сотрудника
   - Или использовать группу email-адресов для получения уведомлений

### Вариант 2: Интеграция с внешним сервисом (альтернатива)

Если вам нужна более продвинутая обработка писем, вы можете интегрировать:

#### FormSpree (бесплатный тариф - 50 сообщений/месяц)
1. Зарегистрируйтесь на https://formspree.io/
2. Создайте новую форму и укажите info@digisec.kz как получателя
3. Обновите компонент ContactForm.tsx - замените `mailto:` на endpoint FormSpree

#### EmailJS (бесплатный тариф - 200 сообщений/месяц)
1. Зарегистрируйтесь на https://www.emailjs.com/
2. Настройте email service и template
3. Обновите ContactForm.tsx для использования EmailJS SDK

#### Web3Forms (бесплатно, без ограничений)
1. Получите API ключ на https://web3forms.com/
2. Обновите форму для отправки на их API

## Проверка работы почты

После настройки почтового ящика:

1. Откройте страницу контактов на вашем сайте
2. Заполните форму тестовыми данными
3. Нажмите "Отправить сообщение"
4. Должен открыться ваш почтовый клиент с предзаполненным письмом
5. Отправьте письмо
6. Проверьте, что письмо пришло на info@digisec.kz

## Рекомендации

1. **Настройте автоответчик** - чтобы клиенты сразу получали подтверждение о получении их обращения

2. **Создайте шаблоны ответов** - для частых вопросов

3. **Настройте фильтры и метки** - для автоматической сортировки входящих обращений

4. **Включите SPAM фильтры** - чтобы избежать спама

5. **Настройте уведомления** - на мобильный телефон или мессенджер для оперативного реагирования
