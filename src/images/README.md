# Изображения для секции "Виды испытаний"

Разместите 6 изображений в этой папке с следующими именами:

1. **code-analysis.jpg** - Анализ исходного кода
2. **security-testing.jpg** - Испытание функций безопасности
3. **stress-test.jpg** - Нагрузочное тестирование
4. **network-audit.jpg** - Обследование сетевой инфраструктуры
5. **security-processes.jpg** - Обследование процессов ИБ
6. **preparation-testing.jpg** - Подготовка к испытаниям

**Важно:** Изображения должны содержать текстовые заголовки, так как в карточках отображаются только изображения и описания (без отдельных текстовых заголовков).

Эти изображения импортируются в `src/pages/index.tsx` и отображаются в секции "Виды испытаний" на главной странице.
